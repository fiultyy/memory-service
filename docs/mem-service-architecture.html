mem-service 架构

agent-os-v2 / services/memory-service — v1→v6 全栈 · KG-based structured recall · 11 ADR · 叠加在 CC file-based memory 之上(不改 MEMORY.md)

总览

mem-service 是一个 KG (Entity + Fact reified) 结构化记忆服务。它把对话事实/实体落 fact 表(正交元数据 + LIF 五维), 按需召回相关 Fact, 叠加在 Claude Code 现有 file-based memory(MEMORY.md 索引)之上, 双轨运行。

三层能力:
① ingest 侧抽取 — 蝴蝶翼 LLM(N=3 投票 + regex fallback, ADR-5b) 解中文盲区(v4)
② 治理 — type-aware decay(idempotent)+ pagerank + LIF 五维 + autoDream(session→KG 增量)+ KG init bootstrap(CC memory 种子)
③ query 侧召回 — α·match+β·centrality+γ·LIF+δ·vec_sim 融合(v6 向量解 synonym/rewrite 盲区)

核心 Flow

① ingest — 文本→KG fact ADR-5b

cli.ingest(text, fact_type, providers) → adapter.extract_facts(text, providers) ├─ providers 可达 → N=3 wings(LLM 抽 + 3 prompt transform)→ 投票(quorum ⌈n/2⌉) │ ├─ confidence ≥ 0.6 → voted facts(exttractor="llm") │ └─ 低置信/空 → regex fallback + merge voted(不丢, extractor="regex") └─ providers 不可达 → _regex_fallback(extractor.extract) → for fact in Extraction.facts: store.put_fact(subject_id, predicate, value, fact_type, extractor=ext_label) → return {entities, facts}

② recall — query→排序 Fact 列表 ADR-4v2 ADR-2v2 ADR-13

cli.recall(query, --vector, weights) → tokens = query_tokens(query) → 候选集 candidates: ├─ search_entities(tokens): entity.name LIKE per token ├─ _facts_for_entities: entity 的 subject/object fact ├─ value substring: fact.value 含 token └─ [use_vec] qv=embed(query) → 扫 active fact, embed(value), cosine ≥ VEC_MIN(0.30) top-N(20) 加入 → centrality = _build_centralities(): networkx pagerank(on-the-fly, 不持久化) → for f in candidates: vec_sim = cosine(qv, embed(f.value)) [use_vec] score_fact(f, query, centrality, vec_sim) = α·match + β·centrality + γ·LIF + δ·vec_sim (α0.5/β0.3/γ0.2/δ0.3) → drop score≤0, sort desc, top_k → [boost] refresh_lif_on_recall: access_count+=1, last_accessed_at=now, seen_sessions 吸收, LIF 重算(强化反馈) → return Fact list

③ autodream — session transcript→KG 增量 ADR-10 ADR-11

PreCompact hook(CC /compact 前触发, stdin JSON {session_id, transcript_path, trigger, cwd}) → bash 读 stdin(jq + python3 fallback) → cli autodream --session --transcript → autodream.autodream(session_id, transcript_path, providers, fact_type) ├─ db.get_conn()(schema init) ├─ consolidate.consolidate()(decay+dedup, 复用 v2/v3) ├─ text = _read_transcript(JSONL user/assistant message.content 拼文本) ├─ result = adapter.extract_facts(text)(蝴蝶翼 LLM, ADR-11 接入 v4) └─ 增量决策 per fact: ├─ ADD: 新 (subject,predicate,value) → put_fact ├─ UPDATE: 已存, 新 session → refresh LIF + absorb session ├─ DELETE: 同 (subject,predicate) 不同 value → 老 supersede + 新 add └─ NOOP: 已存无变化(幂等: 同 transcript 二次全 NOOP) → exit 0 放行 compact(不阻断, 副作用落盘 KG)

④ init-memory — CC memory→KG 种子 ADR-12

cli init-memory [--memory-dir ~/.claude/projects/-home-yy--claude/memory/] → bootstrap.init_memory(memory_dir, providers, fact_type="permanent") for each *.md(sorted): ├─ text = read(.md) ├─ tmp JSONL = {type:user, message:{content:text}} ├─ autodream.autodream(session_id="memory:", tmp, fact_type="permanent") └─ 累加 counts → return {files, added, updated, deleted, noop} (幂等: 重跑 NOOP/UPDATE; 不改 CC MEMORY.md 双轨)

⑤ consolidate — decay + dedup ADR-8 ADR-8v2

cli.consolidate() / autodream phase a ├─ decay pass: LIF *= 0.5**(Δt/half_life) │ half_life: ephemeral=7d / stable=90d / permanent=∞ │ idempotent: 从 original_lif 重基(非累乘, ADR-8 fix) │ LIF < 0.1 → status active→deprecated └─ dedup pass: exact (subject,predicate,value) 重复 → supersede
